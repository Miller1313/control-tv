# Control TV

Control remoto personalizado para televisores con Google TV / Android TV.

## Qué hace
- Busca los televisores en tu Wi-Fi y se empareja con el código que aparece en pantalla
- D-pad, OK, atrás, inicio, encender/apagar, volumen, canales y teclas multimedia
- Apps: YouTube, Netflix, Spotify, Prime Video, Disney+
- Búsqueda rápida en YouTube o en el buscador de Google TV
- Teclado para escribir en el TV
- Cambio de fuente: HDMI 1/2/3, AV, TV/Antena y menú de fuentes
- Botones personalizables (búsquedas, enlaces, teclas o texto), con color

## Descargar
Cada vez que se sube un cambio, GitHub compila la app sola.
Ve a **Releases** (columna derecha del repositorio) y descarga `ControlTV.apk`.

Usa el protocolo Android TV Remote v2 (puertos 6466 y 6467).
